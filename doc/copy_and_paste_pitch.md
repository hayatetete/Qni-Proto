# コピー＆ペースト機能
### 課題
PCEにおける量子誤り検出デモで使用した量子回路の作成を通じ、本機能導入の必要性が明確になりました。
量子アルゴリズムの量子回路を Qni 上で構築する際、量子ゲートを都度ドラッグ＆ドロップで配置する操作は、ゲート数の増加に伴い手間と時間が累積します。
特に CNOT ゲートとの組み合わせ(例：CNOT + Rz、CNOT + 位相、CNOT + H + …）は多くの量子アルゴリズムで登場し、これらを繰り返し配置する場合、この問題が顕著です。

改善目標は、操作回数と所要時間を削減し、回路構築の効率と正確性を高めることです。

### 解決案
Qni にクリップボード機能を導入し、ペースト方向を「右」「下」の二種類で定義します。
ゲート選択時に青い枠のカーソルを表示してペーストの基準とし、複数ゲート選択やワイヤ接続されたゲートのまとまった選択をサポートします。
本機能により量子回路の編集における操作回数と編集時間を低減し、ユーザー生産性を向上させます。

タイムアタックの試算（前提：単一ゲートドラッグ = 1.0 秒、コピー／ペースト = 0.2 秒、回路内調整 = 0.5 秒）では、従来の手順（パレットからドラッグ 52 回）で約 52 秒かかる作業が、本機能を用いることで合計約 15.8 秒となり、作業時間で概ね 70% 程度の削減が見込まれます（ドラッグ回数は 52 回 → 4 回、約 92% 減）。

### 注意点

縦ペーストについては必要性が判明してからの実装にする。

## 1) 基本操作
最小限の操作でコピー・ペーストできるようにして手間を減らす。


### 1-1. ペーストの基準は「カーソル」（明るい緑の四角い枠）とし、量子ビットをクリックした時に表示し複製の基準点とする。 デフォルトはカーソルがない状態。

<img src="image/cursor.png" alt="カーソル" width="200" />

- ※　往来は量子ゲートを選択している「アクティブ状態」のUIとして表示していた枠を、「カーソル」と改め用いる。
- ※　空白にカーソルを表示するときは、Iゲート(単位行列)の選択として扱う。

### 1-2. `Ctrl+C` で現在の選択をクリップボードに保存する。  
### 1-3. `Ctrl+V`（右ペースト）で選択した量子ゲートを同一量子ビットのの右隣に挿入し複製する。

例：アダマールゲートを配置後、`Ctrl+C`でコピーし`Ctrl+V`でペーストする様子。

**アダマールゲートをコピー。**  
<img src="image/HGate.png" alt="Hゲート" width="200" />

**Ctrl+Vでペースト。複製されたゲートは紫の点線の枠で強調される。**  
<img src="image/HGatePaste.png" alt="Hゲートペースト" width="200" />

**既存ゲートがある場合、押し出す（この場合、既存ゲートはXゲート）。**  
<img src="image/HGatePush1.png" alt="Hゲートプッシュ1" width="200" />  
<img src="image/HGatePush2.png" alt="Hゲートプッシュ2" width="200" />

**既存ゲートが制御量子ゲートの場合、ワイヤ接続を壊さないように押し出す（この場合、既存ゲートはCNOTゲート）。**
